9 · Rules — read before you build

  1. Use semantic tokens (--ss-primary), never a raw scale step or a hex literal in a component.
  2. Never put text lighter than --ss-text-muted (ink-700) on white. Everything lighter fails WCAG AA.
  3. One primary button per view. Secondary actions are outline; tertiary are ghost.
  4. Spacing comes from the --ss-1…8 scale or Bootstrap's g-3 / py-4 / gap-2. No arbitrary pixel margins.
  5. Every list has three states: loading (.ss-skeleton), empty (.ss-empty), and loaded.
  6. Keep the prefers-reduced-motion block in theme.css. Do not delete it.
  7. Interactive elements keep the shared :focus-visible outline. Never outline:none without a replacement.
  8. Test every page in Chrome DevTools from iPhone SE (375px) up to XL (1200px+) — that is the range the markers use.
  9. Images always get alt. Icon-only buttons always get aria-label.
  10. Add data-test="..." to anything Playwright needs to click, so tests survive restyling.
